# 기능경기대회

## 기능경기대회란
기능경기대회는 숙련 기술인을 발굴하고 기술의 중요성을 알리기 위해 열리는 기술 경진대회입니다. 한국산업인력공단이 주관하며, 각 시·도의 지방기능경기대회에서 입상하면 전국기능경기대회에 출전할 수 있고, 전국대회 성적이 우수한 선수는 국제기능올림픽(WorldSkills) 국가대표 선발전에 도전할 수 있습니다. 정해진 시간 안에 실제 업무와 비슷한 과제를 직접 수행하고, 그 결과물로 평가받는 실기 중심 대회입니다.
